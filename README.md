# 북한 행정구역 지도

geoBoundaries의 2019년 북한 시·군급(ADM2) 경계 179개를 표시하는 Streamlit 앱입니다. 지도에 마우스를 올리면 원본 지명이 표시됩니다.

## Windows에서 실행

1. [Windows 64비트 실행 ZIP (98.5 MB)](https://github.com/DevYeop/north-korea-admin-map/releases/download/v1.0.0/north-korea-map-windows-x64.zip)을 받습니다.
2. ZIP을 모두 풀고 `North-Korea-Map` 폴더의 `run_map.bat`를 더블클릭합니다.
3. 브라우저가 자동으로 열립니다. 브라우저가 열리지 않으면 명령 창에 표시된 주소를 입력합니다.

실행 ZIP에는 앱, GeoJSON, Python 및 필요한 라이브러리가 포함되어 있습니다.

## 데이터 출처

geoBoundaries PRK ADM2 데이터의 원천 기관은 World Food Programme과 OCHA ROAP입니다. 경계 데이터 라이선스는 CC BY 3.0 IGO입니다. [geoBoundaries](https://www.geoboundaries.org/), [원천 데이터](https://data.humdata.org/dataset/dpr-korea-administrative-boundaries)

[데이터 인용 안내](CITATION-AND-USE-geoBoundaries.txt)와 [메타데이터](geoBoundaries-PRK-ADM2-metaData.json)를 함께 제공합니다.
